# Свадебное приглашение — Shukhrat & Samira

Интерактивное цифровое приглашение (Telegram Mini App / обычный сайт) с анимацией открытия конверта, двумя языками и подтверждением присутствия. Ответы гостей приходят **напрямую в Telegram** — без Google Sheets, Firebase, Supabase и других сторонних сервисов.

---

## Структура проекта

```
project/
├── index.html        — всё приглашение: вёрстка, стили, анимации, форма RSVP
├── api/
│   └── rsvp.js       — serverless-функция Vercel: приём формы и отправка в Telegram
├── vercel.json       — конфигурация деплоя и заголовков кеширования
├── package.json      — тип модулей (ESM) и требуемая версия Node
├── .env.example      — образец переменных окружения для локального запуска
├── .gitignore        — исключения для git
└── README.md         — этот файл
```

### Что делает каждый файл

**`index.html`** — единый самодостаточный файл. Все фотографии, конверт, печать и декор вшиты внутрь в формате base64, поэтому отдельных папок с картинками нет. Снаружи подключаются только Telegram WebApp SDK, GSAP и шрифты Google Fonts. Внутри находятся:

- обложка с конвертом и сургучной печатью, анимация открытия на GSAP;
- основной контент: фото, «Наша история», детали торжества, таймер, дресс-код;
- переключатель языков `[ RU | EN ]` со словарём переводов в объекте `I18N`;
- **форма RSVP** с валидацией и отправкой на `/api/rsvp`.

**`api/rsvp.js`** — серверная функция. Принимает `POST` с JSON, проверяет данные, экранирует HTML, ограничивает частоту запросов и отправляет сообщение в Telegram через Bot API. Токен читается только из переменных окружения — в коде его нет.

**`vercel.json`** — отключает кеширование HTML (чтобы гости всегда видели свежую версию) и ответов API.

**`package.json`** — объявляет `"type": "module"`, поэтому функция в `api/` использует синтаксис `export default`. Требуется Node 18 и выше — в нём доступен глобальный `fetch`.

## Как задеплоить на Vercel

### Вариант 1: через сайт (без терминала)

1. Загрузите все файлы проекта в новый репозиторий на GitHub, **сохранив структуру папок** (`api/rsvp.js` должен лежать именно в папке `api`).
2. Откройте [vercel.com/new](https://vercel.com/new), выберите этот репозиторий.
3. Framework Preset оставьте **Other**, ничего не меняйте, нажмите **Deploy**.
4. После первого деплоя добавьте переменные окружения (см. раздел ниже) и нажмите **Redeploy** — без них форма работать не будет.

### Вариант 2: через терминал

```bash
npm i -g vercel
cd project
vercel            # предварительный деплой
vercel --prod     # боевой деплой
```

Переменные окружения добавляются командами:

```bash
vercel env add BOT_TOKEN production
vercel env add CHAT_ID production
vercel --prod     # передеплой, чтобы переменные подхватились
```

## Как создать Telegram-бота и получить `BOT_TOKEN`

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите имя бота (например, `Shukhrat & Samira RSVP`).
4. Введите username — он должен заканчиваться на `bot` (например, `shukhrat_samira_rsvp_bot`).
5. BotFather пришлёт токен вида `7123456789:AAH...xyz`. Это и есть **`BOT_TOKEN`**.

> Токен даёт полный доступ к боту. Не публикуйте его, не отправляйте в чаты и не коммитьте в репозиторий. Если он утёк — в BotFather выполните `/revoke`.

## Как получить `CHAT_ID`

### Если сообщения должны приходить вам лично

1. Найдите вашего бота по username и нажмите **Start** (без этого бот не имеет права вам писать).
2. Откройте в браузере ссылку, подставив свой токен:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. В ответе найдите блок `"chat":{"id":123456789,...}` — число и есть **`CHAT_ID`**.

Альтернатива: напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш id.

### Если сообщения должны приходить в группу (например, вам и жениху)

1. Создайте группу и добавьте туда своего бота.
2. Отправьте в группу любое сообщение.
3. Откройте `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и найдите `"chat":{"id":-1001234567890,...}`.
4. Id группы **отрицательный** — копируйте вместе со знаком минус.

## Как протестировать отправку

### 1. Проверка самого бота (до деплоя)

Подставьте свои значения и откройте ссылку в браузере:

```
https://api.telegram.org/bot<BOT_TOKEN>/sendMessage?chat_id=<CHAT_ID>&text=Проверка
```

Если сообщение пришло — токен и id верны.

### 2. Проверка API после деплоя

```bash
curl -X POST https://<ваш-проект>.vercel.app/api/rsvp \
  -H "Content-Type: application/json" \
  -d '{"name":"Тест Тестов","wishes":"Проверка"}'
```

Ожидаемый ответ: `{"ok":true}` и сообщение в Telegram.

### 3. Проверка через сайт

Откройте приглашение, нажмите на печать, пролистайте до блока «Подтверждение», выберите ответ, заполните поля и отправьте. Должно появиться «Спасибо ❤️», а в Telegram — уведомление.

### 4. Локальный запуск

```bash
cp .env.example .env.local   # впишите свои BOT_TOKEN и CHAT_ID
npx vercel dev               # откроется http://localhost:3000
```

## Формат сообщения в Telegram

```
💍 Новый ответ с приглашения

👤 Имя:
Алишер Каримов

💬 Пожелания:
Счастья и любви!

🌐 User Agent:
Mozilla/5.0 (iPhone; ...)

📅 Дата:
04.09.2026

🕒 Время:
19:42
```

Если приглашение открыто внутри Telegram, в конце добавляется строка `🔗 Telegram:` с ником гостя — так вы точно знаете, кто ответил.

Дата и время считаются по часовому поясу **Asia/Tashkent**. Чтобы изменить, поправьте константу `TIMEZONE` в начале `api/rsvp.js`.

## Как работает форма

Гость заполняет два поля — имя и пожелания молодожёнам — и нажимает «Отправить». Выбора «приду / не приду» нет.

1. Имя обязательно: минимум 2 символа, только буквы (любого алфавита), пробел, дефис и апостроф. Ошибка подсвечивает поле и показывает подсказку на текущем языке.
2. Пожелания необязательны, ограничены 500 символами.
3. Во время отправки поля и кнопка блокируются, показывается «Отправляем ваш ответ…».
4. При успехе форма закрывается, появляется «Спасибо! Мы получили ваш ответ ❤️» и осыпаются лепестки.
5. **При ошибке введённые данные не теряются** — появляется сообщение и кнопка «Повторить отправку».

Фронтенд отправляет `{ name, wishes, lang, userAgent, clientTime, telegram }`. Сервер также принимает старый формат `{ firstName, lastName, comment }` — он склеивает имя и фамилию, поэтому ранее сохранённые интеграции не сломаются.

Защита на сервере: проверка метода, валидация имени, экранирование HTML, таймаут запроса к Telegram 10 секунд и лимит 5 запросов в минуту с одного IP.

## Совместимость

Проверено на iPhone Safari, Android Chrome, Desktop Chrome, Safari, Edge.

- Размер шрифта полей ввода 16px и более — iOS не увеличивает страницу при фокусе.
- `AbortController` обрывает зависший запрос через 15 секунд.
- Анимации отключаются при системной настройке «уменьшить движение».
- Пересчёт размеров запускается только при реальном изменении ширины окна — на iOS событие `resize` срабатывает и при скрытии адресной строки.
- Таймер обратного отсчёта останавливается, когда вкладка неактивна.

## Частые проблемы

| Симптом | Причина и решение |
|---------|-------------------|
| Форма пишет «Не удалось отправить ответ» | Не добавлены `BOT_TOKEN` / `CHAT_ID` либо не сделан Redeploy после их добавления |
| В логах Vercel `Server is not configured` | То же самое: переменные окружения не видны функции |
| `chat not found` | Вы не нажали Start у бота, или `CHAT_ID` указан без минуса для группы |
| `bot was blocked by the user` | Бот заблокирован в вашем Telegram — разблокируйте |
| Ответ приходит, а «Спасибо» не появляется | Откройте консоль браузера: скорее всего блокировщик режет запрос к `/api/rsvp` |
| Картинки не видны | Все изображения вшиты в `index.html`; убедитесь, что файл загружен целиком, он весит около 1,7 МБ |
